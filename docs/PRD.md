# 山西银行智能营销平台 PRD

**版本**：V1.0
**日期**：2025年5月18日
**状态**：待确认

---

## 一、产品目标

建设一套智能营销平台，实现三项核心能力：

1. **客户洞察报告自动化**：基于行内现有标签和客群数据，自动生成全行/全辖区的客户经营分析报告
2. **客户画像报告自动化**：基于单个客户的内外部数据，自动生成个人/企业客户画像报告
3. **业务流程自动化**：围绕客户拜访场景，打通拜访前→拜访中→拜访后全链路，实现事件驱动的业务自动流转

---

## 二、客户洞察报告

### 2.1 功能说明

系统自动整合行内客户数据，按选定维度（全行 / 分支行 / 客户经理）生成结构化分析报告。

### 2.2 报告内容

```
一、概览
  全行客户总量、AUM总量、存贷款余额

二、客群结构
  按资产分层（新客户 / 成长客户 / 中端客户 / 高净值客户）
  按生命周期阶段分布

三、业务指标
  存款流失率、存款增长率
  贷款转化率
  交叉持有率（客均持有产品数）
  中间业务收入情况

四、重点客群清单
  本月流失预警客户名单
  本月产品到期客户名单
  重点营销目标客群（高价值 / 高潜力）

五、营销机会提示
  交叉销售机会（持有产品少但资质好的客户）
  流失风险提示（资产下降 / 活跃度下降）
```

### 2.3 触发方式

| 方式 | 说明 |
|---|---|
| 手动发起 | 用户选择维度（全行 / 机构 / 客户经理）后生成 |
| 定期自动 | 每月末、每季末自动生成，推送给管理者 |

### 2.4 输出形式

- 在线阅读（Web，含图表）
- PDF导出
- 推送至指定人员（企微 / 邮件）

## 三、客户画像报告

### 3.1 个人客户画像

**触发方式**：客户经理查询 / 营销引擎推荐后跳转

**内容**：

```
一、基本信息
  姓名、手机号（脱敏）、职业、归属机构、客户经理、开户时间

二、持有产品
  存款（活期/定期/大额存单）及余额
  贷款（消费贷/经营贷/按揭）及还款情况
  理财 / 基金 / 保险持有情况
  产品到期提醒（30天内到期列表）

三、金融行为
  近6个月收支趋势
  转账频率、渠道偏好（线上/线下）
  手机银行活跃度

四、标签体系
  资产分层等级（大众/成长/中端/高净值）
  生命周期阶段（新客户/成熟/衰退/流失预警）
  风险偏好（保守/稳健/积极）
  营销响应倾向（高响应/低响应/未触达）

五、风险信息
  信用评级、逾期记录摘要（来自征信）

六、最近触达记录
  最近一次营销触达时间、方式、内容
  客户响应情况
```

### 3.2 企业客户画像

**触发方式**：同个人画像

**内容**：

```
一、企业基本信息
  企业名称、行业门类、注册资本
  实际控制人、关联集团

二、财务情况
  银行授信使用情况（额度/余额）
  存款沉淀情况
  他行贷款情况摘要

三、信用风险
  征信报告摘要
  司法涉诉情况
  舆情摘要（正面/负面/中性）

四、金融行为
  结算账户活跃度
  工资代发情况
  票据/保函使用情况

五、关联关键人
  法定代表人、财务负责人
  → 关联至个人客户画像

六、业务机会
  已覆盖产品 / 未覆盖产品
  供应链金融、现金管理等业务机会提示
```

### 3.3 数据来源

画像数据来自行内现有系统对接（核心系统、信贷系统、理财系统、征信平台、第三方外部数据），无需人工录入。

## 四、业务流程自动化

以**客户拜访**为主线，打通线上线下系统，实现自动化流转。

### 4.1 拜访前

| 动作 | 说明 |
|---|---|
| 自动推送画像 | 客户经理选择拜访客户后，系统自动将画像摘要推送至客户经理手机/PC |
| 事件识别 | 系统自动判断该客户当前是否有：产品即将到期 / 资产异动 / 流失预警 / 生命周期变更 等事件 |
| 生成拜访建议 | 基于事件类型，生成推荐话术、重点产品方向、注意事项 |
| 生成拜访任务 | 自动创建拜访任务，进入待办，进入CRM |

### 4.2 拜访中

| 动作 | 说明 |
|---|---|
| 记录轨迹 | 记录拜访开始时间、地点（GPS），与客户地址自动校验 |
| 实时查看画像 | 客户经理可在移动端实时查看完整画像 |
| 记录沟通要点 | 支持现场录入本次沟通内容（需求 / 承诺 / 异议 / 跟进事项） |

### 4.3 拜访后

| 动作 | 说明 |
|---|---|
| 自动生成拜访纪要 | 基于沟通要点，自动生成结构化纪要 |
| 自动更新客户标签 | 根据沟通内容打标签（如"已面访""贷款意向""有异议待解"） |
| 自动创建跟进任务 | 生成后续待办（3日发送方案 / 7日电话跟进 / 次月再触达） |
| 触发下一业务节点 | 客户有贷款意向→推送至信贷系统；客户有存款意向→生成负债营销任务 |
| 更新营销历史 | 本次拜访记录自动回写至客户画像的触达历史 |

### 4.4 事件驱动机制

系统持续监控客户数据变化，触发以下典型事件时自动启动对应流程：

| 事件类型 | 触发动作 |
|---|---|
| 理财产品到期（7日内） | 自动生成续存营销任务，推送给客户经理 |
| 客户资产大幅流出 | 生成流失预警任务，优先跟进 |
| 客户生命周期阶段变更 | 自动更新标签，触发对应营销旅程 |
| 企业客户外部舆情变化 | 生成风险提示或机会提示，推送给主办客户经理 |
| 客户频繁查看某产品页面 | 识别购买意向，推送产品推荐给客户经理 |

## 五、系统对接

| 对接系统 | 对接内容 |
|---|---|
| 核心系统 | 客户基础信息、账户信息、交易流水 |
| 信贷系统 | 贷款余额、授信额度、还款记录 |
| 理财系统 | 产品持有、到期时间 |
| CRM | 客户经理信息、拜访记录、商机、任务工单 |
| 移动展业（Pad/手机） | 画像推送、任务提醒、拜访记录 |
| 企微/短信/外呼 | 营销触达渠道 |
| 人行征信 | 企业/个人征信摘要 |
| 第三方数据（工商/司法/舆情） | 企业外部数据 |

## 六、非功能性要求

| 要求 | 说明 |
|---|---|
| 性能 | 单客户画像查询响应 ≤ 2秒；洞察报告生成 ≤ 30秒 |
| 安全 | 手机号、证件号脱敏展示；权限按机构/客户经理隔离 |
| 合规 | 自动化决策输出附带说明；触达前校验客户授权状态 |
| 可解释 | AI生成内容可追溯至来源数据或知识库 |
| 高风险动作 | 涉及资金、合同、信息变更的操作须人工确认 |
